# GISS-GC

## Description
This repository contains code as part of an effort in coupling Goddard Institute for Space Studies' [(GISS) Model E](https://simplex.giss.nasa.gov/gcm/) and [GEOS-Chem](https://geoschem.github.io), henceforth GISS-GC. This work was started by Lee Murray in the [GCAP 2.0 project](https://gmd.copernicus.org/articles/14/5789/2021/). The work is part of the [FETCH<sub>4</sub>](https://fetch4.github.io) project. 

GISS Model E is a general circulation model that can simulate many earth system model configurations, including atmospheric chemistry, aerosols, carbon cycle and other tracers, as well as standard atmosphere, ocean, sea ice and land surface components

GEOS-Chem is a global 3D model of atmospheric chemistry traditionally driven by meteorological input from the Goddard Earth Observing System (GEOS) of the NASA Global Modeling and Assimilation Office.
